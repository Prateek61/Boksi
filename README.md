# Boksi

### Clone the repository
```bash
git clone --recurse-submodules git@github.com:Prateek61/Boksi.git 
```

### Generate project files

Note: premake5 required

- Makefile
  ```bash
  premake5 gmake2
  ```

- Visual studio
  ```bash
  premake5 vs2022
  ```
